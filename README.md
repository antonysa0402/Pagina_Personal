## 🧱 Contenido de la página

| Requisito de la guía | Cómo se cumple |
|---|---|
| Encabezado principal con el nombre | `<h1>` dentro de `<header>` |
| Párrafo de presentación personal | Sección "Sobre mí" con `<p>` |
| Lista de intereses o habilidades | Listas `<ul>` y `<li>` |
| Imagen | `<img>` con foto de perfil y texto `alt` |
| Enlaces a redes o sitios favoritos | Etiquetas `<a href="...">` |

## 🏷️ Etiquetas HTML utilizadas

- `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>` – estructura básica
- `<meta>`, `<title>` – información del documento
- `<h1>` a `<h6>` – encabezados jerárquicos
- `<p>` – párrafos
- `<ul>`, `<li>` – listas
- `<img>` – imagen
- `<a>` – enlaces
- `<header>`, `<section>`, `<footer>` – etiquetas semánticas
